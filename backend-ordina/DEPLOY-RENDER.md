# Deploy the ORDINA backend for free: Render (server) + Neon (database)

The Android app keeps tasks on the phone and works offline. The server is used for:
ORDINA AI (the Gemini key lives only here), email accounts, and server backup/sync.

## Already done

- Neon project **`flat-bonus-90867196`** (branch `production`, database `neondb`, AWS us-east-2 Ohio).
  All migrations are applied, including `20261019120000_accounts_sync` (sessions + sync tables).
- A Neon branch **`tests`** is used only by `npm test` (each run creates and drops its own schema).
- `render.yaml` (repo root) describes the service: free plan, region **Ohio** (same as Neon),
  root `backend-ordina`, branch `feature/v1-tasks-ai`, health check `/health`.

## Your steps (about 10 minutes)

1. Open <https://dashboard.render.com> and sign in with the GitHub account that owns `Annithah/ordina`.
2. **New + → Blueprint →** pick `Annithah/ordina`. Render reads `render.yaml` and proposes `ordina-api`.
3. Paste the secret values when asked:
   - `DATABASE_URL`: the line `DATABASE_URL=` from `backend-ordina/.env` on this laptop (pooled, contains `-pooler`).
   - `DATABASE_URL_UNPOOLED`: the line `DATABASE_URL_UNPOOLED=` from the same file.
   - `GEMINI_API_KEY`: the line `GEMINI_API_KEY=` from the same file.
   - `RESEND_API_KEY` and `MAIL_FROM`: leave empty for now (see "Password-reset emails").
   `JWT_SECRET` is generated by Render.
4. Click **Apply**. When the logs show `ORDINA backend listening`, copy the URL at the top
   (`https://ordina-api….onrender.com`) and send it to me. I check `/health` and build the APK with it.

## Password-reset emails (optional, later)

1. Create a free account at <https://resend.com> and an API key.
2. Resend sends to any address only from a domain you verify (Resend → Domains). Until then it
   only delivers to your own Resend sign-up email.
3. In Render → `ordina-api` → Environment: set `RESEND_API_KEY` and `MAIL_FROM`
   (e.g. `ORDINA <no-reply@your-domain>`), then **Save** (Render restarts the service).

Without them, "Forgot password?" says reset is not available yet. The code is never shown in the app.

## Free-plan limits

| | Free plan | What it means |
| --- | --- | --- |
| Render | Sleeps after 15 min idle; waking takes about a minute. No SMTP ports. | The first AI request or sync after a quiet period waits; the app says so. Tasks never wait: they are on the phone. |
| Neon | 0.5 GB storage, suspends after 5 min idle. | Plenty for testing. |
| Gemini free tier | Google may use prompts to improve its products. | Disclosed in `store/privacy-policy.md`. |

## What production mode does

- Runs `prisma migrate deploy` on every start (direct connection), then starts the server (pooled).
- Refuses to start without a strong `JWT_SECRET`.
- Rate limits: 200/min overall, 30/min for AI, 20 sign-in attempts and 10 reset attempts per 15 min.
- Logs only method, path, status and timing. Never passwords, tokens, codes, tasks or prompts.
- Public account-deletion page: `https://<your-url>/account/delete`.

## Local development

```bash
cd backend-ordina
npm install
copy .env.example .env   # then fill in the Neon strings (or a local Postgres)
npm run db:setup         # apply migrations
npm run dev
npm test                 # unit tests + database tests (needs TEST_DATABASE_URL)
```
